# OPEN THIS PROJECT IN UNITY

## Project path
D:\Unity\MyFantasyWorld

## Steps
1. Open **Unity Hub**
2. Click **Open** (or Add) → select folder `D:\Unity\MyFantasyWorld`
3. Open with **Unity 6000.5.0f1** (already used to create this project)
4. First open will import assets — wait (can take a long time)
5. If scripts ask about Input System, choose **Yes** / use Input System package (already in project)
6. Read guide: `Assets/MyWorld/Docs/SECTION_BY_SECTION_BUILD_BIBLE.md`
7. Create your scene: File → New Scene → Save As `Assets/MyWorld/Scenes/MainWorld.unity`
8. Start Section 1 (Terrain) from the bible
