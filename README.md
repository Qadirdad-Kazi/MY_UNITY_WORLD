## Quick start

1. Open this repo in **Unity Hub** (Unity 6 / URP)
2. Open scene `Assets/Scenes/MY WORLD`
3. Read **[`MASTER_GUIDE.md`](Assets/MyWorld/Docs/MASTER_GUIDE.md)**
4. Do **Part A (Player)** → **Part B (Car)** → Play and visit the map
5. Then build world sections 1–6

```text
Local path example:
D:\Github Clones\MY_UNITY_WORLD
```
