# Assets included in this pack + what else to download

## How to import included assets

1. Open your **new** URP project  
2. Copy folders from `AssetsToImport/` into the project `Assets/` folder  
3. Let Unity finish importing (can take a long time)  
4. Prefer importing **one pack at a time** if your PC is slow  

See `HowToImport/IMPORT_ORDER.txt`

# SECTION MAP — what you need for each world part

## 1) Terrain / ground painting
**Included (if copy succeeded):**  
`Game_Textures`, `Game_Terrains`, Free Island textures (if present)

**Download if missing:**
- PBR terrain texture packs (sand, grass, dirt, rock, snow, mud)
- Search: `terrain textures PBR`, `ground textures free`

## 2) Trees / forest / mountains
**Included:** `ALP_Assets`, `Forst` (import `Conifers_URP.unitypackage`), `Game_RocksAndVegetation`

**Download if you want more:**
- Extra oak/pine/jungle/palm URP tree packs
- Search: `trees URP`, `palm trees URP`, `jungle vegetation URP`

## 3) Grass / flowers
**Included:** ALP GrassFlowers, BushGrassBend tool

**Download:** more terrain detail grass if needed  
Search: `terrain grass flowers`

## 4) Rocks / cliffs
**Included:** `Free_Rocks`, rocks inside Game vegetation pack, Game stone/desert models

**Download:** cliff megapack if you want bigger canyons  
Search: `cliffs rocks URP`

## 5) Water / beach
**Included:** `AQUAS-Lite`, pier/boat models if present, Phantom water if copied

**Download (recommended upgrade):**
- Better **URP water**  
Search: `stylized water URP`, `URP water`

## 6) Roads
**Included:** `EasyRoads3D`, `KajamansRoads`

**Download:** EasyRoads dirt/medieval road materials if asphalt looks too modern  
Search: `EasyRoads dirt road`, `medieval road textures`

## 7) Bridges
**Included:** `3DWorldInSeconds_Bridges`

**Download:** extra fantasy bridges if needed  
Search: `wooden bridge`, `stone bridge fantasy`

## 8) Fantasy village / houses
**Included:** `3DForge_FantasyExteriors` (main kit), Game sheds/well

**Download:**
- Market stalls / medieval props  
- Interior tavern/shop  
Search: `medieval props`, `market stall`, `tavern interior URP`

## 9) Player character
**Scripts included:** PlayerMotor (works with capsule)

**Download optional:**
- `Starter Assets Third Person`  
- Fantasy hero character model

## 10) Cars
**Included models (if copied):** Game car folders (Jeep, etc.)

**Download:**
- Clean WheelCollider-ready cars OR any FBX + you add WheelColliders  
Search: `unity wheelcollider car`, `driveable vehicles`

**Script:** `CarController` (already in Scripts)

## 11) Bikes
**Included models (if copied):** Jawa / street bike folders

**Download:** more motorcycle packs if needed  
**Script:** `BikeController`

## 12) Planes
**Usually NOT included**

**Download required:**
- Simple airplane model URP  
Search: `airplane low poly`, `aircraft model unity`

**Script:** `PlaneController` (ready)

## 13) Boats
**Included (if copied):** `Alstra_Boats`

**Script:** `BoatController`

## 14) Sky / lighting
**Included:** `AllSkyFree`

**Download optional:** more weather skies  
Search: `skybox free`

## 15) Day/night + weather
**Script included:** `DayNightCycle`

**Download:**
- Rain VFX URP  
- Optional full weather system  
Search: `rain VFX URP`, `day night cycle URP`

## 16) Audio
**Usually limited / not fully copied**

**Download required for living world:**
- Waves, wind, forest birds, river, soft village ambience  
Search: `nature ambience`, `ocean waves loop`

**Script:** `AmbientZoneAudio`

## 17) Wildlife / NPCs
**Not fully included as a complete life pack**

**Download:**
- Birds, animals, fantasy villagers  
Search: `birds flying`, `stylized animals URP`, `fantasy villagers`

## 18) Castle / ruins / caves
**Partial** (village kit may help; dedicated castle often missing)

**Download:**
- Ruins pack, castle modular, cave pack  
Search: `ruins pack`, `fantasy castle modular`, `cave environment`

## 19) Snow / desert / swamp / jungle biomes
**Partial textures/models only**

**Download per biome:**
- Snow terrain layers + winter trees  
- Desert rocks + sand  
- Swamp trees/fog props  
- Jungle vegetation / palms

# DO NOT prioritize downloading

- HDRP-only packs (wrong pipeline)
- Giant modern cities (style conflict)
- Huge RPG frameworks before your land exists
